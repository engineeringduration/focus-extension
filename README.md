# Focus Extension

A productivity browser extension designed to help you stay focused online by minimising distractions.  
Built with JavaScript, CSS, and HTML.

[![Watch the demo](https://img.youtube.com/vi/8KLk6-6UYpY/0.jpg)](https://youtu.be/8KLk6-6UYpY?si=Dmtpz-XMQMDLzr0T)

## Features

- Block distracting websites
- Focus session of each 25 min 
- Simple, user-friendly interface
- Light and efficient—no data tracking
  

## Installation

1. Clone or download this repository.
2. In your browser, go to the extensions page:
    - Chrome: `chrome://extensions/`
    - Firefox: `about:addons`
3. Enable "Developer mode" and load the `focus-extension` directory.

## Usage

- Click the Focus Extension icon in your browser.
- Set your focus session length and break times.
- Add websites to your blocklist as needed.
- Start your focus session and boost your productivity!

## Development

1. Clone the repo:
    ```bash
    git clone https://github.com/engineeringduration/focus-extension.git
    ```
2. Open the folder in your favourite code editor.
3. Edit the JavaScript, CSS, or HTML files as needed.
4. Reload the extension in your browser to see changes.
